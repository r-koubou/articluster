ArtiCluster
===========

ArtiCluster is conversion and management tool that supports articulation mapping files across DAWs.

## Overview

We define a DAW-independent intermediate format (referred to as “Universal Definition” in ArtiCluster) and convert it into key switch and articulation definition files for each DAW.


I have published the files I converted myself in the GitHub repository below.

https://github.com/r-koubou/ArticulationMappingFiles

This software is the successor to [KeySwitchManager](https://github.com/r-koubou/KeySwitchManager) and was redesigned from scratch to address several issues.


## Supported DAW

- Cubase / Nuendo (*.expressionmap)
- Cakewalk / Sonar (*.artmap)
- Logic Pro (*.plist)
- Studio Pro / Studio One (*.keyswitch)


## Requirements

- [.NET 10](https://dotnet.microsoft.com/)


## Installation and Update

### Installation

```sh
dotnet tool install --global ArtiCluster
```

### Update

```sh
dotnet tool update --global ArtiCluster
```

### Uninstall

```sh
dotnet tool uninstall --global ArtiCluster
```


## ArtiCluster Command Usage

```sh
Usage:
  articluster [command] [options]

Options:
  -v, --verbose   Enables verbose logging output
  -?, -h, --help  Show help and usage information
  --version       Show version information

Commands:
  new <path/to/output>              Create a Universal Definition file
  convert <input-dir> <output-dir>  Convert to DAW-specific format.
```

## Getting Started

### 1. Create a Universal Definition file using the `new` command.

```sh
articluster new ./MyInstrument
```

### 2. Edit the generated Universal Definition file to define your articulations and MIDI messages.

You can use any text editor to edit the YAML file. The file structure is defined by the schema, which specifies the required fields and their formats.

**We also offer tools that can be edited online.**

https://articluster-editor.pages.dev/

### 3. Use the `convert` command to generate DAW-specific articulation mapping files from your Universal Definition files.

```sh
articluster convert ./input-directory ./output-directory
```

## About Universal Definition (*.yaml)

The `Universal Definition` is an intermediate format used to convert data into keyswitch and articulation definition files for each DAW.

The following is a sample Universal Definition File.

```yaml
FormatVersion: 1
Id: 56ca2345-1ef9-4a96-95d0-9c8c210b9e9d
Author: Example Author
ManufacturerName: Example Manufacturer
ProductName: Example Product
PatchName: Example Patch
Description: Example Description
Articulations:
- Name: Articulation Name
  MidiMessages:
  - Status: 144
    Data1: 60
    Data2: 100
```

## MidiMessage

A MIDI message within the articulation, consisting of a status byte and two data bytes

#### Examples

```yaml
Status: 144
Data1: 64
Data2: 100
```

```yaml

Data1: 64
Data2: 100
```
